# Lab Management System

A web-based Lab Management System developed using PHP, MySQL, HTML, CSS, and JavaScript.

## Features

* User Authentication
* Staff Management
* Laboratory Record Management
* Database Integration
* Responsive User Interface

## Technologies Used

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* PHPMailer

## Installation

1. Install XAMPP.
2. Start Apache and MySQL.
3. Import `lab.sql` into phpMyAdmin.
4. Place the project folder inside `htdocs`.
5. Open `http://localhost/project-folder-name`.
